# Card Catalog Tracker

This source describes a secure networking tracker designed to manage contacts, detailing its architecture and setup procedures. The main result is a separation between the browser and the database connection via an Express API.

## Key details

- Contacts can be added with name, company, role, where met, notes, and priority.
- Priority is limited to `high`, `medium`, or `low` and is enforced in the database.
- The frontend uses React 18 + Vite, which builds a plain static site served by Vercel's CDN.
- The frontend talks to an Express API, which in turn communicates with the Neon Data API.
- The sign-in process uses Neon Managed Better Auth, which issues a signed token that expires after about 15 minutes.
- Row Level Security is enabled on the `contacts` table, comparing the row's owner against the signed-in user.
- The `user_id` column in the `contacts` table has a default value generated by `auth.user_id()`, ensuring the browser never sends a `user_id`.
