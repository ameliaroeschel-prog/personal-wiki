# Large Language Model

A neural network trained on large amounts of text to predict the next word (token). Chat assistants, and the local Gemma model behind this wiki, are large language models.

## Related concepts

- [[Corpus]] — the training text; a model can only use words it has seen.
- [[Loss]] — the training signal that measures how wrong its next-word predictions are.
- [[AI Agents]] — systems that use a language model to take actions.
