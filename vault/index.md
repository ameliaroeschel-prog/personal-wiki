## Concepts

- [[AI Agents]] — AI systems that use a language model to take actions and complete tasks, not just answer questions
- [[Corpus]] — The body of text a language model is trained on
- [[Customer Success]] — The function that makes sure customers adopt a product and get value from it after the sale
- [[EdTech Industry]] — Companies that build technology products for schools and learners
- [[Evaluation Suite]] — A fixed set of tests run the same way before and after a change, so results are comparable
- [[Exploration Rate]] — How often a reinforcement-learning agent takes a random action instead of its best guess
- [[Financial Modeling]] — Building spreadsheet models that project a business's revenue, costs and returns
- [[Large Language Model]] — A neural network trained on text to predict the next word, the basis of tools like ChatGPT, Claude and Gemma
- [[Learning Rate]] — How big a step the model takes each time it updates its weights
- [[Loss]] — A number measuring how wrong the model's predictions are; training tries to push it down
- [[Replay Memory]] — The buffer of recent decisions a DQN agent re-samples to learn from
- [[Row Level Security]] — A Postgres feature where the database itself decides which rows each user may see or change
- [[Token Authentication]] — Signing in by receiving a short-lived signed token that each service can verify
